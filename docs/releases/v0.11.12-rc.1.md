## Acceptance boundary

This artifact is the first official RC, but it is not yet the accepted field baseline.

Not yet performed for RC1:

- update-in-place installation on the target Samsung SM-T500;
- preservation of application data and layouts during update;
- physical startup and navigation acceptance;
- EpicEFI Mega144H7 USB read-only connection acceptance;
- physical ESP32 BLE queue evidence and reconnect acceptance;
- extended in-vehicle stability acceptance.

The previously accepted PR #34 field APK remains the accepted installed baseline until this RC completes a separately authorized physical acceptance procedure.

## Safety boundary

RC1 remains strictly read-only with respect to the ECU. It does not write tune pages, burn changes, control outputs, send virtual-input commands, expose a generic raw ECU-command interface, or perform firmware operations.
