## Important safety warning

1207 is **not ECU read-only**.

With an exact matching generated INI, current ECU generation/signature, and complete verified TuneSnapshot, the application can perform guarded semantic RAM tune writes and an explicit separate Burn.

If your purpose is only connection/compatibility testing, do not edit tune values or press Burn.

The WebView does not own raw production write authority. Unknown/ambiguous hardware, profile mismatches, stale identity, and offline/detached states fail closed before tuning authority.

## Existing physical evidence

A Samsung SM-A137F / Android 14 test with the current MEGA144H7 firmware/profile showed:

- exact firmware/profile match;
- complete 60,764-byte TuneSnapshot acquisition;
- approximately 19.5 Hz live streaming against the 20 Hz target;
- zero CRC/protocol errors in the captured session;
- multiple verified semantic RAM writes;
- major live-project payload reduction versus 1206;
- no new managed uncaught crash captured in that session.

That evidence applies only to the tested combination.

## Requested compatibility evidence

Please include, where possible:

1. Android device/model and Android version.
2. ECU board/hardware.
3. Exact TunerStudio/firmware signature shown by the app.
4. The fact that the INI is genuinely generated for that ECU/firmware build.
5. Whether INI import succeeds.
6. Whether the connection reaches profile match, preflight, complete TuneSnapshot and stable streaming.
7. Whether live values appear plausible.
8. Any unsupported INI construct, fail-closed state, crash or major performance issue.
9. An exported diagnostics report when safe to share.

Do not post private keys, credentials, sensitive vehicle information, or other secrets in public reports.

## Known remaining performance work

Measured remaining costs in the current phone evidence include profile restore, post-write workspace reconstruction, on-demand offline-project construction, and initial TuneSnapshot acquisition. The former continuous giant live-project payload path is no longer the dominant normal-live workload.
